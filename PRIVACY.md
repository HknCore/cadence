# Datenschutz

Cadence sammelt keine persönlichen Daten und sendet nichts an den Entwickler oder an Dritte.

- **Keine Telemetrie, keine Werbung, kein Konto.** Cadence funktioniert vollständig lokal.
- **Profile und Einstellungen** liegen nur auf deinem Computer (Profilordner unter *Einstellungen → Profile*).
- **Messwerte** (Bildzeiten, Aufnahmen) bleiben im Arbeitsspeicher. Sie werden nur gespeichert, wenn du sie selbst als CSV oder Bild exportierst.
- **Update-Prüfung** (nur Version von GitHub): Cadence fragt beim Start die öffentliche GitHub-Schnittstelle nach der neuesten Version. Dabei werden keine persönlichen Daten übertragen, abschaltbar unter *Einstellungen → Über Cadence*. Die Version aus dem Microsoft Store prüft nicht selbst, dort kommen Updates über den Store.
- **„Problem melden“** erstellt einen Diagnosebericht nur auf Klick, legt ihn in deine Zwischenablage und öffnet GitHub im Browser. Ob und was du davon teilst, entscheidest du selbst.

Fragen: über die [Issues auf GitHub](https://github.com/HknCore/cadence/issues).
